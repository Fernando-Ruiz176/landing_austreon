# Austreon - Landing Page de Próxima Generación

Este documento detalla los requisitos técnicos, de diseño y funcionales para el desarrollo de la landing page institucional de **Austreon**, una firma líder en automatizaciones de alto nivel, arquitectura de mercados financieros e Inteligencia Artificial Sintética.

## 🚀 Visión del Proyecto
Crear una experiencia web inmersiva que no solo informe, sino que demuestre la capacidad técnica y la sofisticación de Austreon. La interfaz debe sentirse "viva", utilizando micro-interacciones, visualización de datos en tiempo real y una estética minimalista-futurista.

---

## 🏗️ Arquitectura de la Landing Page

### 1. Hero Section (Impacto Total)
- **Visual:** Fondo dinámico con partículas o redes neuronales (Canvas/Three.js) que reaccionen al movimiento del mouse.
- **Copy:** Título de alto impacto que fusione los tres pilares (Ej: "Orquestando el Futuro: IA Sintética y Arquitectura de Mercados").
- **CTA:** Botón principal de "Explorar Ecosistema" y secundario para "Ver Proyectos".

### 2. Core Pillars (Propuesta de Valor)
Tres bloques interactivos con estética de "vidrio esmerilado" (glassmorphism):
- **Automatización Inteligente:** Eficiencia operativa sin precedentes.
- **Arquitectura de Mercados:** Estructuras financieras optimizadas mediante algoritmos.
- **IA Sintética:** Generación y modelado de datos avanzados para toma de decisiones.

### 3. Proyectos en Desarrollo (Showcase)
- Sección estilo "Portfolio Grid" con filtros rápidos.
- Cada proyecto contará con una tarjeta expandible que detalle:
  - Estado del desarrollo (Beta, R&D, Live).
  - Tecnologías clave aplicadas.
  - Impacto esperado.

### 4. Alianzas Estratégicas (Sección Dinámica)
- Slider o rejilla de logos en escala de grises que cobran color al pasar el cursor.
- Espacios reservados ("Placeholder") con la leyenda "Alianzas Estratégicas: Próximamente" para generar expectativa sobre las negociaciones actuales.

### 5. Roadmap & Visión
- Una línea de tiempo vertical o interactiva que muestre el camino de la empresa y los hitos tecnológicos que planea alcanzar.

### 6. Pie de Página (Footer)
- Enlaces a redes sociales profesionales (LinkedIn, Twitter/X).
- Newsletter de suscripción para actualizaciones técnicas.
- Aviso legal y contacto.

---

## 🛠️ Stack Tecnológico Sugerido
- **Framework:** React.js (con Vite para máxima velocidad).
- **Lenguaje:** TypeScript (para robustez y escalabilidad).
- **Estilo:** CSS Moderno (Vanilla CSS con variables o CSS Modules) para evitar dependencias pesadas y mantener un diseño único.
- **Animaciones:** Framer Motion para transiciones suaves y efectos de scroll.
- **Iconografía:** Lucide React o SVG personalizados de estilo técnico/lineal.

---

## 🎨 Guía de Estilo (Look & Feel)
- **Paleta de Colores:** 
  - Primario: Negro profundo (#0A0A0A) / Gris Carbón.
  - Acento: Azul Eléctrico o Verde Neón sutil (representando datos e IA).
  - Tipografía: Sans-serif de alta legibilidad (ej. Inter, Geist o Montserrat) en diferentes pesos.
- **Efectos:** Desenfoques de fondo (backdrop-filter), gradientes lineales muy suaves y bordes ultra-finos.

---

## 📋 Requisitos de Implementación para Antigravity
1. **Performance:** Puntuación de 90+ en Google Lighthouse (SEO, Accesibilidad, Rendimiento).
2. **Responsividad:** Adaptabilidad perfecta desde monitores Ultrawide hasta dispositivos móviles.
3. **Mantenibilidad:** Código modular donde cada sección de la landing sea un componente independiente.
4. **Escalabilidad:** Estructura preparada para añadir una sección de blog o documentación técnica en el futuro.
